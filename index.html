Como hacer tu propia página web

💻 En computadora:

1. Entra a github.com y crea cuenta.

2. Crea repositorio: tu-nombre.github.io

3. Sube tu archivo index.html

4. Activa Pages en Settings.

📱 En teléfono:

1. Descarga la app de GitHub en Play Store.

2. Crea cuenta y repositorio igual: tu-nombre.github.io

3. Dale en Add file > Create new file y pega el código.

4. Es más fácil si usas Chrome en modo escritorio.
